## Кратко

Версия добавляет отдельные shaded-сборки для Java 21 и Java 25, убирает локальный переключатель bStats из конфигурации и расширяет документацию готовыми рабочими примерами.

## Для игроков

- Изменён только способ поставки JAR; игровые команды и combat-tag поведение сохранены.

## Для администраторов

- Удалён параметр `metrics` из `config.yml`, чтобы bStats не отключался случайным изменением основной конфигурации.
- Добавлено пояснение, что глобальный opt-out bStats в `plugins/bStats/config.yml` сохраняется и не обходится.
- Добавлены варианты `pnRelog-1.0.1-java21.jar` и `pnRelog-1.0.1-java25.jar`.
- Добавлены подробные комментарии для bStats и Java-вариантов в `README.md`.

## Для разработчиков

- Сохранён bStats plugin id `33313`.
- Добавлены Gradle-задачи `compileJava21`, `shadowJava21`, `compileJava25` и `shadowJava25`.
- Сохранена совместимость исходного варианта с target Java 17.

## Добавлено

- Добавлены shaded JAR для Java 21 и Java 25.
- Добавлены пояснения по корректному opt-out bStats.

## Изменено

- Версия проекта изменена на `1.0.1`.
- Команда `releaseJar` теперь собирает базовый, Java 21 и Java 25 варианты.

## Исправлено

- Исправлена возможность отключить bStats через локальный параметр pnRelog `metrics`.

## Совместимость

- Базовый JAR использует target Java 17.
- Java 21 JAR требует Java 21 или новее.
- Java 25 JAR требует Java 25 или новее.
- Глобальный opt-out bStats продолжает поддерживаться.

## Миграция

1. Выбери JAR под установленную Java.
2. Замени старый JAR в папке `plugins/`.
3. Сделай полный restart сервера.
4. Не добавляй `metrics` обратно в `config.yml`: pnRelog больше не использует этот параметр.

## Важно

> Никакой плагин не может технически запретить владельцу сервера изменить файлы `plugins` или глобальный opt-out bStats. pnRelog не обходит официальный механизм отключения bStats.
